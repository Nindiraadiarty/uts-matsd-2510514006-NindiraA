## Struktur Repositori
Repositori ini terdiri dari beberapa folder utama yang menyimpan komponen tugas:
* **`00_identitas/`**: Berisi file dokumen terkait identitas mahasiswa.
* **`01_tulisan_tangan/`**: Berisi file scan/foto hasil pengerjaan tugas tulis tangan.
* **`02_matlab/`**: Berisi script, fungsi, atau file source code utama MATLAB (`.m`).
* **`03_figures/`**: Berisi plot atau grafik hasil eksekusi program MATLAB.
* **`04_screenshots/`**: Berisi tangkapan layar (bukti running) hasil jalannya aplikasi/script.
* **`05_video_link.md`**: Dokumen berisi tautan video penjelasan atau demonstrasi aplikasi.

## Prasyarat & Cara Menjalankan
Untuk menjalankan kode program di repositori ini, pastikan Anda telah memiliki akun MATLAB.

### Langkah-langkah:
1. Clone atau unduh repositori ini ke komputer Anda.
2. Buka MATLAB.
3. Arahkan *Current Folder* MATLAB ke folder `02_matlab` di komputer Anda.
4. Buka file script utama (misalnya `main.m` atau file `.m` lainnya).
5. Klik tombol **Run** pada editor MATLAB atau ketik nama file di *Command Window*.
